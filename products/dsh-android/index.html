Features

What 1.4.1 shows.

Taken from the English UI on a Pixel 10a running app 1.4.1 (26), and from the Google Play listing where noted.

AI coding agent

The assistant describes itself as an AI coding agent inside DeepSeek Harness. It can read, write, and edit files in the workspace, search the web and read images, run commands and long-running tasks in the sandbox, and plan multi-step work with a todo list.

Your own API key

Models & accounts is where you connect a key. On this device that row shows Connected. A model you can use is DeepSeek-V4.1-Flash.

Extensions

+ Plug-in installer, a Compatibility gate, and Community catalog marked External · unreviewed. The gate can confirm only prebuilt interpreted JavaScript, without native payloads or process execution. Package lifecycle hooks never run. The catalog is third-party and not a HenWorks endorsement.

Private workspace

Workspace & storage says files stay in the app’s private storage. Share or save any file from the list, or one the agent just wrote. Renaming changes only the display name.

Eight languages

English, Traditional Chinese, Simplified Chinese, Japanese, Korean, German, Spanish, and Russian. App chrome changes immediately. Upstream DSH and plug-in WebViews stay in English so third-party content stays consistent.

Runtime from Play

About shows runtime status Runtime ready and update source Google Play. Google Play updates the app and the bundled runtime. Reviewed pure JavaScript plug-ins use the signed catalog and never execute install scripts.

What the assistant says it can do.

In the “Who are you” thread the reply lists workspace files, web search and images, sandbox commands, and a todo list for multi-step work. The composer reads “Message DSH…” and the session badge reads online.

Reviewed plug-ins, and a catalog that is not.

Extensions lists + Plug-in installer, Compatibility gate, and Community catalog with the badge External · unreviewed. Reviewed catalog actions load after the managed runtime restarts. The community catalog is third-party. Listing an item is not a HenWorks endorsement.

Files stay in private storage.

Workspace & storage keeps the file list on the device. You can share or save a file from that list. The free plan may show ads. Upgrade · Remove ads is a one-time purchase; this device shows US$7.99. The Play listing prices it in local currency, so the amount can differ by region.

On the phone

DSH Android has no HenWorks account, and this release does not include Firebase Analytics. The workspace, API credentials you enter, and conversations stay in the app’s private storage unless a provider you choose needs the request sent directly to it. HenWorks does not run an inference relay for this release. Verified Pro does not request ads. See the privacy policy.

Play listing and skins

The Google Play listing still describes a secure four-color skin schema import that does not run install scripts or modify upstream DSH. Settings in 1.4.1 has no Skins section.
