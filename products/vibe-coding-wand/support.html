  2. 按住語音鍵說話，鬆開後文字會進剪貼板。

How to use

vibe coding wand turns a Bluetooth voice remote into on-device dictation on this Mac. No account.

Pair first, then hold the mic

The remote must appear in system Bluetooth settings. When dictation finishes, text is copied to the clipboard.

Install

  1. Install from the Mac App Store. Requires macOS 26 or later.
  2. Open the app and allow Bluetooth when asked.

Pair the remote

  1. Hold Home and Menu until the remote appears in Bluetooth settings.
  2. Finish pairing in system Bluetooth.
  3. Return to the app and confirm it is connected. If several remotes are nearby, pick which one handles voice.

Dictate

  1. Allow Speech Recognition the first time you dictate. Apple runs recognition on this computer.
  2. Hold the mic key and speak. On release, the transcript is copied.
  3. Paste into your editor, terminal, or chat.

Trial and unlock

Free to download. Try for 7 days, then unlock with a USD 7.99 Apple In-App Purchase. No subscription.

使い方

vibe coding wand は Bluetooth 音声リモコンを、この Mac 上のオンデバイス文字入力にします。アカウントは不要です。

先にペアリングし、マイクを押したまま話す

リモコンはシステムの Bluetooth 設定に出ている必要があります。認識が終わるとテキストはクリップボードへコピーされます。

入手

  1. Mac App Store からインストール。macOS 26 以降。
  2. App を開き、求められたら Bluetooth を許可します。

ペアリング

  1. ホームとメニューを同時長押しし、Bluetooth 設定に出るまで待ちます。
  2. システムの Bluetooth でペアリングを完了します。
  3. App に戻り、接続を確認します。複数あるときは音声に使う一台を選びます。

文字入力

  1. 初回は音声認識を許可します。認識は Apple がこのコンピュータ上で行います。
  2. マイクを押したまま話します。離すとテキストがコピーされます。
  3. エディタ、ターミナル、チャットへ貼り付けます。

試用と解除

無料ダウンロード。7日間試用のあと、Apple の App 内課金 USD 7.99 で買い切り。サブスクリプションはありません。
