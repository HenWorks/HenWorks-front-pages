Setup Guide

Last updated 7 September 2026

DSH is a remote control for DeepSeek Harness. It needs a harness running on a computer you own. This page sets that up, end to end.

⚠️
Read this before you install the app

DSH is a client, not a service. If you do not already run DeepSeek Harness on your own computer, the app has nothing to connect to and cannot do anything. There is no DSH cloud, and no account to sign up for.

What you need

  • A computer running DeepSeek Harness. Version 0.1.1 or newer. Watching and steering sessions from the phone needs 0.1.2 or newer — see Version notes below.
  • Node.js and the dsh command already working on that computer.
  • An iPhone on iOS 17 or later, on the same network as the computer, or able to reach it over your own remote access.

Step 1 — Install the host plugin

DSH talks to a small plugin that runs inside your own harness. Install it into the profile you use (web is the default):

dsh plugin --profile web add @henworks/dsh-mobile

Use the dsh plugin command rather than npm install. It resolves the harness's own packages correctly; a raw npm install inside the profile tries to pull its own copies and fails with a peer dependency conflict.

Step 2 — Run the setup step

dsh plugin --profile web exec @henworks/dsh-mobile setup

This creates the mobile access configuration under ~/.dsh/mobile-access/ and issues a local TLS certificate so the phone talks to your computer over HTTPS. It prints the address it configured, for example https://192.168.1.20:3443. Do not skip this step: without it the plugin loads but has nothing to serve.

Step 3 — Start the harness and open the Mobile card

dsh --profile web

In the web interface, open the Mobile card in the lower-left corner, switch mobile access on, and create a pairing key. A QR code appears. The pairing window is short-lived on purpose — create it when you are ready to scan.

Step 4 — Pair your iPhone

  1. Open DSH on the iPhone and tap Pair.
  2. Scan the QR code, or copy the pairing link and paste it into the field below the scanner.
  3. Approve with Face ID, Touch ID, or your device passcode.

The key that grants access to your computer is generated inside the iPhone's Secure Enclave and never leaves the device. Pair once; the phone remembers the computer after that.

Version notes

The plugin is tested against DeepSeek Harness 0.1.1-rc.2 and 0.1.2-rc.1, and behaves differently on each:

  • 0.1.2 and newer — everything works: session list, live streaming, sending prompts, approving tools, stopping a running turn.
  • 0.1.1 — pairing, Face ID challenge-response and device management work, but the harness has no session controller, so there are no sessions to show. The app says so plainly instead of failing on every screen. Update the harness to 0.1.2 or newer to use it properly.

Installing the plugin never stops your harness from starting, on either version.

If something goes wrong

The app says this computer is too old for mobile sessions

The harness is older than 0.1.2. Update it on the computer; nothing needs to change on the phone.

dsh will not start after installing the plugin

Remove the plugin and start again, then tell us what the error said:

dsh plugin --profile web remove @henworks/dsh-mobile

The phone cannot find or reach the computer

Both devices must be on the same network, and your firewall must allow the port the setup step printed. The app connects only to the address you gave it — nothing is relayed through a server of ours, so if the computer is unreachable the phone genuinely cannot get to it.

The pairing link expired

Pairing windows are deliberately short. Create a fresh one from the Mobile card and scan it straight away.

The camera will not scan

Grant camera access in Settings › DSH, or use the paste field instead — the pairing link works exactly the same way.

Removing everything

On the phone, open Settings in DSH and tap Unpair; this deletes the Secure Enclave key. On the computer:

dsh plugin --profile web remove @henworks/dsh-mobile

Delete ~/.dsh/mobile-access/ if you also want the paired-device list and the local certificate gone.

Open source and attribution

@henworks/dsh-mobile is a fork of the dsh-mobile project, used under the Apache License 2.0, extended with the API that this iPhone app needs. It is not published or endorsed by the upstream project, and DSH is not affiliated with DeepSeek. Do not install this fork and upstream dsh-mobile into the same profile — they serve the same routes and bind the same port.

Still stuck?

Email info@henworks.com with your DeepSeek Harness version (dsh --version), your iOS version, and what the app or the terminal said. The Diagnostics tab in the app reports the host version and the capabilities it advertises, which is usually the fastest way to see what is wrong.
