Hermes Agent
on Android

Hermes running on your phone. Multi-model chat, a real Linux terminal, openBMB 1B on Snapdragon, and a desktop companion on your own network. Not a client for an existing Hermes gateway.

Get it on Google Play Desktop companion

Built on the open-source hermes-agent framework (Nous Research). This is the Android app itself — it does not connect to a Hermes gateway you already run elsewhere. Bring your own API key. No HenWorks cloud account.

What 3.0 actually ships

Multi-model, your keys

OpenAI, Anthropic, Google, OpenRouter. No cloud account. Paste a key and start.

On-device on Snapdragon

openBMB 1B on the Snapdragon NPU. Good for short chats and Q&A. Long agent tasks still go through a cloud provider.

Real Linux terminal

bash, Python, git, and code execution on the phone — not a fake shell.

Chat Skin (Labs)

One tap from terminal to chat bubbles, expandable tool cards, live typing, photo attach.

Hermes HUD

Sessions, tools, memory, cron, MCP. Check install and Repair install when something is missing.

Phone + computer

Run on Computer (mesh) and Desktop Handoff. NaCl-encrypted, pair once, no cloud in between.

How it works

Install

Get Hermes Agent from Google Play.

Connect

Add an API key, or use openBMB 1B on Snapdragon with no cloud key.

Work

Chat, run the terminal, or open the HUD.

Pair (optional)

Scan the companion QR to hand off with your PC.

Hermes Pro

The app is free with ads. Hermes Pro is a one-time purchase that removes them permanently. No subscription.

Requirements
  • Android device, ~200MB for initial setup
  • API key from a supported provider — or a Snapdragon device for on-device openBMB 1B
  • Internet for cloud providers; the 1B model stays on device
